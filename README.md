## 🗂️ Two File Types — Why Both?

This repo uses a deliberate mix:

| Type | Used For | When to Use |
|------|----------|-------------|
| 📓 `.ipynb` notebooks | Concept exploration, notes, step-by-step walkthroughs | Learning new topics |
| 🐍 `.py` scripts | Standalone problem solving, clean implementations | Practicing specific problems |

Notebooks are great for explaining *what* and *why*. Scripts are great for practicing *how*.
